# 🎓 SeatSync Allocation

SeatSync Allocation is an intelligent seat allocation system designed to automate seating arrangements for universities, schools, examinations, conferences, and events. The platform eliminates manual seat assignments by providing a fast, organised, and efficient allocation process.

## ✨ Features

- 🪑 Automated seat allocation
- 👨‍🎓 Student registration and management
- 🏫 Room and seat management
- 🔍 Search allocated seats instantly
- 📊 Administrative dashboard
- ⚡ Fast and efficient allocation algorithm
- 🔒 Secure user authentication
- 📱 Responsive and user-friendly interface

---

## 🚀 Why SeatSync?

Traditional seat allocation is often time-consuming and prone to human error. SeatSync streamlines the entire process by automatically assigning seats based on predefined rules, improving accuracy while saving administrative time.

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/flames778/seatsync-allocation-.git
```

2. Navigate into the project

```bash
cd seatsync-allocation-
```

3. Open the project in your preferred code editor.

4. Configure your Firebase project credentials.

5. Launch `index.html` or deploy using Firebase Hosting.
